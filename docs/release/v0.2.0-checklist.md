## 升级说明

1. Chart 版本 `0.1.0 → 0.2.0`，`appVersion 0.1.0 → 0.2.0`。
2. API 契约变化：删除 `GET /v1/runbooks`、`GET /v1/audit-events`；新增 Incident 时间线 `/evidence` 端点与 opaque cursor 分页（新增 `INVALID_CURSOR` / `FILTER_CHANGED` 错误语义），客户端需适配。
3. 镜像 tag 固定为 `v0.2.0`（digest 见上），禁止 `latest`。
4. `kubeVersion >= 1.31.0` 不变；数据库迁移由 alembic migrations job 自动执行。

## 已知限制

1. **DeepSeek 模型质量未达标**：r5 严格决策合同 28/36（危险动作 0/36），r6 有界迭代 28/36→26/36 回退后已还原 v4；不放行云端自动修复。
2. **云上部署为 gate-down 受控演示**：阿里云单节点 k3s create/smoke/destroy 真实走通，但诊断用 `fake` provider、未调用真实 DeepSeek、未跑真实邮件闭环，未宣称云端自动修复。
3. **chart NetworkPolicy 有 3 处缺口**（migrations→postgres、metrics scrape、API-server egress），cloud-init k3s 镜像源、cloud-smoke.sh 陈旧等问题在云上以运行时 patch / 等价命令修复，未固化进 chart。
4. **buildcache 残留仅存在于 git 历史**（提交 `fa3e282`、`1ca7456`），当前工作树干净（`git ls-files 'buildcache/**'` 为空）。

6. **DeepSeek 评估样本量仅 36 case**；cpu 与 adversarial-dependency 类别的 r6 回退是单样本抽样，方差未在多次运行确认。
